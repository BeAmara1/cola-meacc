# Tipos de variáveis

```
Variável
├── Qualitativa (categórica)
│   ├── Nominal   → categorias sem ordem natural (ex: time de futebol, cor/raça, religião)
│   └── Ordinal   → categorias com ordem natural (ex: nível de satisfação, escolaridade)
└── Quantitativa (numérica)
    ├── Discreta   → valores contáveis, geralmente inteiros (ex: nº de homicídios, nº de filhos)
    └── Contínua   → qualquer valor num intervalo (ex: renda per capita, taxa de desemprego, altura)
```

## Exemplos rápidos (padrão de prova)

| Variável | Tipo |
|---|---|
| Quantidade de homicídios no Brasil | Quantitativa discreta |
| Time de futebol | Qualitativa nominal |
| Taxa de desemprego | Quantitativa contínua |
| Nível de satisfação com o governo | Qualitativa ordinal |
| Denominação religiosa | Qualitativa nominal |
| Renda per capita | Quantitativa contínua |

## Por que isso importa

O tipo da variável define:
- Que **gráfico** faz sentido (barras/setores para qualitativa; histograma/linha/boxplot para quantitativa)
- Que **medida de resumo** faz sentido (moda/frequência para qualitativa; média, mediana, desvio padrão para quantitativa)
- Se dá para calcular **correlação de Pearson** (só entre duas quantitativas)
